# Recipe Finder Website 🍽️

A recipe search website built using HTML, CSS, and JavaScript.  
It fetches real-time recipe data using TheMealDB API.

## Features
- Search recipes by name
- View recipe details and ingredients
- Uses external API
- Responsive UI

## Tech Stack
- HTML
- CSS
- JavaScript
- TheMealDB API
